# Mesto

Интерактивная фотогалерея на JavaScript и Vite. Профиль, аватар, карточки и лайки хранятся на API Яндекс Практикума. Автор может удалить свою карточку. Кнопка «i» показывает актуальные сведения о фотографии, владельце и пользователях, поставивших лайк.

[Открыть Mesto на GitHub Pages](https://daniil10062005.github.io/mesto-production/)

## Доступ к API

Проект работает с группой `apf-cohort-203`. При первом открытии введите личный учебный токен этой группы. После успешной загрузки он сохраняется до закрытия вкладки. Для автоматического входа при локальной разработке можно указать `VITE_MESTO_TOKEN` в файле `.env.local`, который исключён из Git.

## Разработка

Используйте Node.js 22.12 или новее.

```sh
npm ci
npm run dev
```

Команда `npm run build` создаёт сборку в каталоге `dist/`.

## Публикация

После push в ветку `main` GitHub Actions собирает сайт и отправляет содержимое `dist/` в публичный репозиторий `DaniiL10062005/mesto-production`. Для этого используется ключ развёртывания из секрета `PUBLIC_PAGES_DEPLOY_KEY`. GitHub Pages обслуживает сайт из корня ветки `main` публичного репозитория.

Для ручной публикации с компьютера, у которого есть доступ на запись в этот репозиторий:

```sh
npm run deploy
```
