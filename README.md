# Mesto

Проектная работа десятого спринта Яндекс Практикума. На странице можно редактировать профиль и аватар, добавлять фотографии мест, открывать их, ставить лайки и удалять карточки. Формы проверяют поля при вводе. Изменения хранятся до перезагрузки страницы.

## Запуск

Понадобится Node.js 22.12+ или Node.js 20 версии 20.19 и выше.

```sh
npm ci
npm run dev
```

Vite откроет страницу в браузере. Команда `npm run build` создаёт готовую сборку в каталоге `dist/`.
